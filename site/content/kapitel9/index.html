    Kapitel 9 – Datenbeschaffung¶

    Was du in diesem Kapitel lernst¶

    • Warum Daten der Rohstoff jeder KI sind
    • Welche Datenquellen es gibt und wie du sie erschließt
    • Was Datenqualität ausmacht (die „5 V" und Gütekriterien)
    • Welche rechtlichen Punkte du bei der Beschaffung beachten musst

    9.1 Daten als Rohstoff der KI¶

    KI lernt aus Daten. Ohne passende Daten gibt es keine gute KI – „garbage in, garbage out". Die Datenbeschaffung ist deshalb oft der aufwendigste Teil eines KI-Projekts.

    9.2 Datenquellen¶

    flowchart TD
    A([Datenquellen]) --> B([Interne Daten])
    A --> C([Externe Daten])
    B --> B1([CRM, ERP, Logs])
    B --> B2([Dokumente, E-Mails])
    C --> C1([Open Data, Statistikämter])
    C --> C2([Gekaufte Daten, APIs])
    Quelle Beispiel Hinweis
    Interne Systeme CRM, ERP, Warenwirtschaft oft ungenutzter Schatz
    Dokumente Verträge, Berichte, E-Mails unstrukturiert, aber wertvoll
    Öffentliche Daten Statistikämter, Open Data kostenlos, gut zum Anreichern
    APIs / Dienste Wetter, Geodaten aktuell, oft kostenpflichtig
    Sensoren (IoT) Maschinendaten Basis für Predictive Maintenance

    9.3 Datenqualität: die „V" und Gütekriterien¶

    Gütekriterien guter Daten:

    Kriterium Frage
    Vollständigkeit Fehlen Werte?
    Korrektheit Sind die Werte richtig?
    Aktualität Sind die Daten aktuell genug?
    Konsistenz Widersprechen sich Daten?
    Relevanz Passen die Daten zum Ziel?

    Menge ist nicht Qualität

    Viele Daten (Volume) helfen nur, wenn sie korrekt, relevant und aktuell sind. Schlechte Daten führen zu schlechten KI-Ergebnissen – egal wie modern das Modell ist.

    9.4 Rechtliche Leitplanken¶

    • Personenbezogene Daten unterliegen der DSGVO (siehe Kapitel 33).
    • Urheber-/Nutzungsrechte bei externen Daten prüfen.
    • Zweckbindung: Daten nur für den vereinbarten Zweck nutzen.

    Copilot-Prompt zum Ausprobieren:

    1
2
3
    Ich möchte für den Use Case "[Use Case]" Daten beschaffen. Erstelle eine
Checkliste: mögliche interne und externe Datenquellen, Qualitätskriterien und
rechtliche Punkte, die ich prüfen muss.

    Kurzübungen¶

    Grundlagen Datenquellen einordnen

    Sind die folgenden Datenquellen intern oder extern?

    1. Das eigene CRM-System
    2. Wetterdaten über eine öffentliche API
    3. Gescannte Eingangsrechnungen
    4. Statistiken des Statistischen Bundesamts
    Tipp

    Intern = entsteht im eigenen Unternehmen.

    Lösung
    1. Intern
    2. Extern
    3. Intern
    4. Extern
    Fortgeschritten Datenqualität beurteilen

    Lass dir von Copilot helfen, einen Datensatz zu beurteilen:

    1
2
3
    Ich habe eine Kundenliste mit den Spalten Name, E-Mail, Kaufdatum, Umsatz.
Welche Qualitätsprobleme können auftreten und wie erkenne ich sie? Nenne je
Problem eine Prüfmethode.

    Ergänze mindestens ein Qualitätsproblem, das Copilot nicht genannt hat.

    Tipp

    Denke an fehlende Werte, Dubletten, falsche Formate und veraltete Einträge.

    Lösung

    Bewertungskriterien: mehrere realistische Qualitätsprobleme (fehlende Werte, Dubletten, Formatfehler, veraltete Daten) mit passender Prüfmethode; eigene sinnvolle Ergänzung.

    Workshop¶

    Workshop Datenbeschaffungsplan

    Szenario: Für einen KI-Use-Case (z. B. Absatzprognose) müsst ihr die Datenbeschaffung planen.

    Aufgabe (allein oder in der Lerngruppe):

    1. Legt einen konkreten Use Case fest.
    2. Erstellt eine Datenlandkarte: Welche Daten werden gebraucht, wo liegen sie (intern/extern), wer ist verantwortlich?
    3. Bewertet je Quelle die Qualität und benennt Risiken (Lücken, Rechte, Aktualität).
    4. Entwickelt einen Beschaffungsplan mit Schritten und rechtlichen Prüfpunkten.
    5. Nutzt Copilot für Checklisten und Struktur – prüft die Vorschläge kritisch.

    Deliverables: Datenlandkarte + Qualitäts-/Risikobewertung + Beschaffungsplan mit rechtlichen Prüfpunkten.

    Tipp

    Klärt früh, welche Daten personenbezogen sind – das entscheidet über den DSGVO-Aufwand.

    Lösung

    Bewertungskriterien: vollständige Datenlandkarte mit Verantwortlichkeiten; realistische Qualitäts-/Risikobewertung; umsetzbarer Beschaffungsplan inkl. Rechtsprüfung; Copilot sinnvoll eingesetzt.
